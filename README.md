# AutomatedPneumoniaDetectionProject

You can run the backend code on Google Colab and download the trained model to your local system. I personally used Sublime Text Editor for my frontend.

My dataset had a combination of Normal and Pneumonia affected lungs' X-rays. In addition to the X-rays of the adult lungs, I made use of lung X-rays of children during both training and testing.
